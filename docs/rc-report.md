## 9. 属于 future tuning、不是 release blocker 的问题

1. **分析与编译的 token 预算调优**:仍有 6–8/25 分析在 8192 预算下降级(残余,跨轮波动)。确定性层(triage/target/机械分类)保证流程安全,但意图/target 质量下降 → 建议后续按模型族设预算表(需新的实测数据,不在本轮盲调)。
2. **模型漂移产出旧模板标题**(rc22 的 `Task Goal`):属于模型行为,可在输出守卫里加「不得出现旧模板标题」的软检查(非阻塞)。
3. **REBUILD 的扩写幅度**:rc20 等需要更贴近最小充分;属阈值/提示调优,需更多真实样本。
4. **凭空量化(59 次)**:多数是「1./2.」编号与平台参数(如 16:9、8 秒)被我的粗粒度指标计入;真正的无证据量化已有守卫拦截。指标本身需要细化。
5. **`reasoning_effort` 在该模型上几乎不缩短推理** → 无法靠档位省预算,只能给足预算。
